# Конспекты ПМИ ПМ-ПУ

В репозитории хранятся исходники конспектов в формате LaTeX. При изменении файлов `.tex` PDF пересобираются автоматически.

## Исправления

Если вы нашли ошибку, неточность или опечатку, можете:

### Сообщить об ошибке

[Создайте заявку](https://github.com/dariaviktorova/pmpu_conspects/issues/new). Укажите семестр, предмет и номер страницы в PDF. Кратко опишите проблему.

### Предложить исправление

1. В папке [notes](notes/) выберите семестр и предмет. Откройте файл `.tex` для редактирования через значок карандаша. Если GitHub предложит создать копию репозитория, выберите **Fork this repository**.
2. Внесите правку и сохраните её через **Commit changes… → Propose changes**.
3. Кратко опишите правку. Проверьте, что в поле **base repository** указан `dariaviktorova/pmpu_conspects`, а в поле **base** — `main`. Отправьте запрос через **Create pull request**.
